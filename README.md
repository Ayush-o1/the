# Ayush Kumar

Portfolio of Ayush Kumar, a software engineer in Bengaluru. Six projects, each built around a
failure, with a small simulation of each one that runs in the browser. The page works as plain
HTML and adds a 3D flight on top when the browser can show it.

Live: https://ayush-o1.github.io/the/

Run it locally:

```sh
npm install
npm run dev
```

`npm run check` runs lint, a build, the logic tests and the size budgets. `npm run test:e2e` runs
the browser tests. See [ARCHITECTURE.md](ARCHITECTURE.md) for how the code is laid out.
